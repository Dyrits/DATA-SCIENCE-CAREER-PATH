# Data Science Career Path

Projects from the Codecademy Data Science career path.

## About The Project

The path covers data analysis fundamentals, with a strong SQL component. This repository contains the section projects, one directory per section:

- 01 - The Importance of Data and SQL Basics (Create a Table)
- 02 - SQL - Basics
- 03 - SQL - Intermediate
- 05 - Analyze Real Data with SQL (Usage Funnels with Warby Parker)

### Built With

- SQL
- Jupyter Notebook
